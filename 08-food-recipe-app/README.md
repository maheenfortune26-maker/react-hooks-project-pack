# Food Recipe App

**Hooks used:** useState, useEffect, useRef, Context API, React Router

**Notes:** Requires a recipe API key (e.g. Spoonacular at spoonacular.com/food-api), or swap for TheMealDB which is free/keyless. Add key to .env as VITE_RECIPE_API_KEY if using Spoonacular.

## Setup
```
npm install
npm run dev
```
