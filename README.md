# React Hooks Project Pack

8 hook-focused React apps, each in its own folder as a standalone Vite project.

| # | Folder | Project | Needs API key? |
|---|--------|---------|-----------------|
| 1 | 01-accordion | Accordion (Single & Multi-select) | No |
| 2 | 02-random-color-generator | Random Color Generator | No |
| 3 | 03-star-rating | Star Rating Component | No |
| 4 | 04-image-slider | Image Slider with API | No (public image API) |
| 5 | 05-load-more-products | Load More Products / Infinite List | No (public products API) |
| 6 | 06-nested-tree-view | Nested Tree View / Recursive Menu | No |
| 7 | 07-weather-app | Weather App | **Yes — OpenWeatherMap** |
| 8 | 08-food-recipe-app | Food Recipe App | **Yes — Spoonacular (or use free TheMealDB instead)** |

## Running any project
\`\`\`
cd <folder-name>
npm install
npm run dev
\`\`\`

## Pushing to GitHub
\`\`\`
git init
git add .
git commit -m "Scaffold 8 hook projects"
git remote add origin <your-repo-url>
git push -u origin main
\`\`\`
